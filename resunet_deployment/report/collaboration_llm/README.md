# 大模型协作记录

本目录挑选与大模型五例对话，覆盖训练决策、量化与数据契约、算子集成、时序/CDC 诊断以及 上位机–FPGA 端到端流程，避免只展示硬件 RTL 工作。

**来源说明：** 记录取自真实协作线程。所有数值只采用线程或工程报告中已经出现的证据。部分训练日志来自当时的对话，未随仓库提供。各案例的“自我纠错轨迹”同时记录模型自我修正和用户补充约束，避免把用户纠正误写成模型独立发现。

## 记录列表

| 文件 | 阶段 | 主题 |
|---|---|---|
| [`dialogue1.md`](dialogue1.md) | 训练 | 训练路线审计：从低 Dice 和震荡中确定主线 |
| [`dialogue2.md`](dialogue2.md) | 量化与数据接口 | 量化、2.5D 输入与 DDR 地址契约审计 |
| [`dialogue3.md`](dialogue3.md) | 算子集成与联合上板 | MKDC 从独立算子接入工程并完成分层板测 |
| [`dialogue4.md`](dialogue4.md) | 优化与时序收敛 | 从 hold 违例和 CDC 报告定位真实时序根因 |
| [`dialogue5.md`](dialogue5.md) | 端到端联调与优化 | 上位机–FPGA–CT/STL 端到端闭环与性能证据管理 |

这些记录体现的协作方式是：先冻结目标和边界，再读取工程证据；遇到失败时区分 RTL、测试平台、约束和工具状态；最后只用实际日志、Golden 或实现报告确认结论。

## 沉淀出的可复用技能

| 技能 | 来源案例 | 适用场景 | 失败来源 | 失效条件 |
|---|---|---|---|---|
| 训练路线审计与安全早停 | [一](dialogue1.md) | 训练指标震荡、模型迁移或蒸馏效果不稳定 | 高学习率重置、只看全局 Dice、把训练正常结束误认为效果达标 | 无固定划分或没有病例级输出 |
| 量化输入与 DDR 数据契约审计 | [二](dialogue2.md) | 输入从上位机/网络进入 DDR，且有 2.5D、切片边界或多种 BIN 布局 | 把 225 层文件当成 255 层、signed INT8 当 UINT8、沿用旧 patch 协议 | dtype、布局或中心层边界未冻结 |
| 分层 Golden 集成验收 | [三](dialogue3.md) | 多个算子共享 DDR、描述符和网络协议，需逐步接入真实工程 | 描述符校验失败、满容量权重装载覆盖、把小尺寸链路误称为完整模型 | 没有对应 bitstream 或 Golden |
| Vivado 时序与 CDC 证据化诊断 | [四](dialogue4.md) | 出现 setup/hold 违例、跨时钟域路径或约束可疑 | 只看 WNS、把 CDC 路径当组合逻辑、用宽泛例外约束掩盖同域路径 | 没有同版本实现报告 |
| 端到端阶段计时、身份校验与实验归档 | [五](dialogue5.md) | 上位机/ARM、网络、FPGA 推理和后处理组成多阶段流水 | 纯推理与完整墙钟混用、回读身份不匹配当成硬件错误、两次耗时差写成优化收益 | 身份字段缺失或测试条件不一致 |

这些技能的共同失效条件是：缺少冻结的输入/Golden、没有对应版本的 bitstream 或实现报告、测试条件不一致，或者只保留最终 PASS 而删除失败日志和修正过程。

## 记录边界

- 所有“仿真通过”只表示对应测试范围的功能或 Golden 通过，不代表完整 512×512 整网或最终板级稳定性已经验证；最终结果见 [`README.md`](../../README.md) 与 [`board/`](../../board/)。
- 所有性能数值必须与输入尺寸、模型数量、频率、是否包含通信和后处理一起引用，不能脱离测试条件单独宣传。
- 技能的可复用实现位于 `skill/`；本目录说明这些技能是从哪些失败或观察中总结出来的。
