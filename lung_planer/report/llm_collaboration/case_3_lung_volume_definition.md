# 案例 3：肺总体积与表面积定义

## 用户提示词

现在的肺总体积其实有问题，理论上来说应该计算的是两片肺叶包裹的内部部分。而不是单纯计算各 STL 的闭合体积直接相加，直接相加会导致血管或者支气管等的部分和肺叶的部分重复计算。

## 模型回答与行动

重新定义三个指标：

- **肺总体积：** 参与计算的肺实体的几何并集体积。
- **肺外表面积：** 只统计并集外边界中落入切除区域的部分。
- **新切除面面积：** 计算肺并集内部对应的切面区域。

同时区分 `Bronchus_plan` 肺段规划实体与真实支气管模型。

## 自我纠错轨迹

- 模型起初称电脑端三项指标已经修正，并提到布尔并集。
- 用户进一步追问边界定义后，模型重新检查实现并纠正：
  - 肺总体积仍在直接累加各 STL；
  - 外表面积仍可能计入内部接口；
  - 新切除面也只是近似。
- 因此先前的说法不能当作正确参考。

## 验证证据与结果

- 对话中核对到：逐 STL 体积之和与布尔并集体积仅相差约 0.95 cm³，说明该病例当前实体重叠很少。
- 这不证明直接相加在一般情况下是正确的。
- 模型据此提出：优先使用完整的左右肺表面，没有时才使用肺段并集，且不用凸包去填补肺门或肺间空隙。

## 可复用经验

- 先明确临床或几何指标的定义，再检查实现的数据来源和边界语义。
- 区分「该病例误差小」与「算法对所有病例正确」。
- 把假设、近似与精确几何量明确标注。
