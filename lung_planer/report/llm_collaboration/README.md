# 大模型协作记录

依据《选题指南（AMD）》第 3.3.3.1、3.3.4、3.3.5.2、3.3.5.3 节整理。从 ESDC 工作区的对话中选取五段最能体现工程价值的协作记录，每段单独成文。

## 说明

- 「用户提示词」引用对话中真实出现的原话。
- 「模型回答与行动」和「自我纠错轨迹」为摘要，数据以当时的对话和对应的实测记录为准。
- 「自我纠错轨迹」记录模型的结论如何因用户追问、源码核查或测量证据而修正。
- 每篇的结构相同：对话主题、用户提示词、模型回答与行动、自我纠错轨迹、验证证据与结果、可复用经验。
