# 案例 4：中心线提取的板端加速归因

## 用户提示词

请对中心线提取做板端加速，并给出可归因的端到端结果。要求用三个指定 STL 做真实板端基准，采用同口径、分阶段计时，报告中位总耗时及相对历史 PL 基准的加速倍数。

请把整体提速拆成两部分：软件算法优化的增益，以及现有 PL 距离核的增益；分别报告系统总收益和硬件单独贡献，不能把总加速全部归功于 FPGA。不要只看硬件调用就下结论，要结合掩膜、骨架逐体素对照和完整结果校验修正归因偏差，并分析主要收益来自哪些软件环节（如 CPU 体素化、图处理、原生 Lee 优化）。

请报告现有真实距离 PL 的额外节省与倍数、掩膜/骨架逐体素比对结果、完整中心线误差、回归测试通过项数。以输出等价性约束性能优化。对尚未上板验证的新 PL 扩展，明确列为未完成或待集成，不要写成已实现成果。

## 模型回答与行动

完成真实板端基准后，把整体提速拆成两部分：软件算法优化的增益，以及现有 PL 距离核的增益。没有把总加速全部归功于 FPGA。

## 自我纠错轨迹

- 依据掩膜、骨架逐体素对照和完整结果校验，修正了「只看硬件调用」可能造成的归因偏差。
- 主要收益来自 CPU 体素化、图处理和原生 Lee 优化；PL 距离模块提供额外但较小的收益。
- 新的 PL 扩展当时尚未上板，明确列为未完成。

## 验证证据与结果

| 项目                | 结果                                    |
| ----------------- | ------------------------------------- |
| 三个指定 STL 的三轮中位总耗时 | 历史 PL 基准 271.244 秒降至 65.884 秒，约 4.12× |
| 现有真实距离 PL 的额外节省   | 约 9.015 秒，约 1.137×                    |
| 掩膜、骨架逐体素比对        | 通过                                    |
| 完整中心线误差           | 满足 1e-10 mm                           |
| 回归测试              | 56 项通过                                |

## 可复用经验

- 用端到端同口径基准，并分阶段计时。
- 分别报告系统总收益和硬件单独贡献。
- 以输出等价性约束性能优化。
- 区分已上板验证和仍待集成的扩展。
